# כוח בהדרגה 50+

אפליקציית רשת לאימוני קליסטניקס (אימון במשקל הגוף) למתחילים מעל גיל 50.

- 6 רמות: אימון של כ-5 דקות בבית ברמה 1, ועד כ-28 דקות בגינת כושר ברמה 6
- 3 אימונים בשבוע, עם יום מנוחה ביניהם
- 3 שלבים בכל רמה, ומבחן מעבר בסוף כל רמה, באישור עצמי
- נגן אימון עם טיימר, יומן התקדמות וסרטוני הדגמה
- הנתונים נשמרים בדפדפן של הטלפון בלבד. יש ייצוא וייבוא של קובץ גיבוי (JSON)

## פתיחה בטלפון

האפליקציה מתפרסמת דרך GitHub Pages מהענף `main`. אחרי הפתיחה אפשר להוסיף אותה למסך הבית. ההוראות נמצאות במסך "גיבוי" שבאפליקציה.

## לפני שמתחילים

כדאי לקבל אישור מרופא לפני תחילת אימוני כוח, במיוחד אם יש לחץ דם גבוה, בעיית לב, סוכרת או כאבים במפרקים.
